Ke Ala Hele Makalae (Kapaʻa Bike Path)

A paved coastal shared-use path running along Kauaʻi's east side, popular for walking, biking, and running with leashed dogs.

📍 Lihi Park, Kapaʻa, HI 96746

🐶 Dog rules

Leashed dogs (max 2 per handler) are explicitly permitted on this county path per Kauaʻi County code — waste bags must be carried and used. One stretch is off-limits: from the makai end of Nalu Road (the entrance to Lydgate Beach Park) to Hikinaakala Heiau.

🕐 Hours

Open daily

✨ Amenities

  • Paved path
  • Ocean views
